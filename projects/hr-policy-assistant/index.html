AI-Powered HR Policy Assistant

A proposed source-grounded assistant that answers questions from public HR policy documents, cites supporting passages, and acknowledges when evidence is missing.

LLMsRetrieval-Augmented GenerationEvaluationResponsible AI

Problem

HR policies can be long and difficult to navigate. A carefully scoped assistant could help users locate relevant passages, but only if it reliably grounds responses in approved source documents.

Proposed implementation

Build a small retrieval-augmented generation (RAG) prototype over public or synthetic policy documents. Return source snippets with each answer and clearly say when the document set does not answer the question.

Evaluation plan

Create a test set of realistic questions and expected source passages. Measure answer correctness, citation support, retrieval quality, abstention behavior, and failure cases. Include questions that are deliberately unanswerable from the documents.

Safety boundaries

This would be an educational prototype, not legal advice or an authoritative HR decision system. It should not process confidential employee records and should direct high-impact or ambiguous questions to an appropriate human expert.
